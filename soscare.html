Résumé du Projet

IoT Platform est une solution complète de télésurveillance médicale connectée permettant le suivi en temps réel de patients via des montres connectées. La plateforme permet la détection et la gestion des urgences médicales (SOS, chutes, anomalies cardiaques) avec une interface dédiée pour les centres d'appels et les professionnels de santé.

L'architecture repose sur des microservices avec TCP Service pour la communication avec les montres (protocole 3G Text), API Service pour la logique métier, PostgreSQL pour le stockage et Redis pour le cache. Le frontend est développé avec Next.js 15 et offre une interface temps réel pour le centre d'appels.

Une attention particulière a été portée à la sécurité des données médicales (conformité RGPD, chiffrement AES-256, audit logs) et à la fiabilité du système (auto-reconnexion des montres, mécanismes de heartbeat, backup automatique quotidien).

Microservices
TCP Service
Communication avec les montres connectées via protocole 3G Text (port 9000). Gère le parsing des trames, les heartbeats (LK), les données GPS (UD), les alarmes (AL) et les commandes (FIND, CR, UPLOAD).
Node.js net.Server Port: 9000
API Service
API RESTful (port 3000) pour la gestion des utilisateurs, des dossiers médicaux, des abonnements, des devices et des alertes. Gère l'authentification JWT, le RBAC et la communication avec PostgreSQL.
Express.js JWT Port: 3000
Frontend (Next.js)
Interface utilisateur pour le centre d'appels, le dashboard médical, la gestion des patients et l'administration. Affichage en temps réel des alertes et localisation GPS.
Next.js 15 Tailwind CSS Port: 3001
PostgreSQL
Base de données relationnelle stockant les utilisateurs, dossiers médicaux, localisations GPS, alertes, abonnements et journaux d'audit. Chiffrement des données sensibles avec pgcrypto.
PostgreSQL 15 pgAdmin pgcrypto
Redis
Cache pour les sessions utilisateur et les données fréquemment accédées. Stockage des tokens invalides (blacklist) et gestion des files d'attente.
Redis 7 Sessions Cache
Nginx (Reverse Proxy)
Reverse proxy pour le routage du trafic : API (/api/*), pgAdmin (/pgadmin/*), frontend (/*). Load balancing et gestion SSL.
Nginx Reverse Proxy Port: 80

Sécurité & Conformité

Authentification JWT

Tokens signés, durée de vie limitée, refresh tokens httpOnly.

RBAC

Contrôle d'accès basé sur les rôles (Call Center, User).

Chiffrement

Données sensibles chiffrées (AES-256), mots de passe hashés (bcrypt).

Audit logs

Traçabilité complète des actions critiques.

Backup quotidien

Sauvegarde automatique PostgreSQL avec rétention 30 jours.

RGPD compliant

Conformité avec les réglementations européennes sur les données de santé.
